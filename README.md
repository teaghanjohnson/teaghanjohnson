# Hi, I'm Teaghan 👋

I'm a third year Computer Science student at Wilfrid Laurier University building full stack web applications with Java, TypeScript, React, and Python. My goal is to be an engineer in my community, building software that helps local businesses run better and grow.

## 🏀 Featured Project: CourtVision
A deployed full stack NBA stats platform.
- **Backend:** Spring Boot REST API (Java, JPA/Hibernate) on PostgreSQL, with read only endpoints supporting query filtering and pagination
- **Data:** Python scraping pipeline (BeautifulSoup, pandas) covering 30 teams across 5 seasons
- **Frontend:** Next.js + TypeScript with sortable stat tables and an animated Three.js 3D interface
- **Deployment:** Dockerized, with the frontend on Vercel and the backend on Railway

## 🔭 Other Projects
- **ThunderBear:** Full stack inventory management app for an MMA gym (Node.js, Express, PostgreSQL, EJS, MVC)
- **NBA Match Predictor:** ML model predicting game outcomes with 400+ features (scikit-learn, XGBoost, Streamlit)
- **Battleship:** Interactive game with a computer opponent, built with OOP and tested with Jest
- **Weather Dashboard:** Dynamic theming driven by live weather data (Visual Crossing and Giphy APIs)

## 🌱 Currently Learning
- AI integration: bringing LLMs and AI features into real web applications
- Machine learning: building on my match predictor and working toward AI powered features in CourtVision
- Building practical tools for local businesses
